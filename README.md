# 静态演示 Demo（纯前端，可公开托管）

不依赖后端、模型服务或 API Key 的浏览器内演示原型，用于在作品集/帖子里提供一个可点开交互的入口。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 对话页面与样式，引入下面两个脚本 |
| `qa_data.js` | 内置数据集：车型白名单、越界关键词、预置问答对、兜底回复与工具调用轨迹（JSON 兼容字面量） |
| `app.js` | 浏览器内分流与轻量检索：实体白名单 → 意图关键词 → 词覆盖阈值 → 预置答案；含前端会话记忆计数、指代增强与工具轨迹渲染 |
| `_calibrate.py` | 离线校准脚本：复刻前端逻辑，在 `eval/eval_set.jsonl` 上复核四类分流与阈值 |

## 本地预览

直接用浏览器打开 `index.html` 即可；若个别浏览器限制本地脚本，可在本目录起静态服务：

```bash
cd demo
python -m http.server 8080
# 浏览器访问 http://localhost:8080/
```

## 部署到静态托管

三个文件均为纯静态资源，可直接部署到任意静态托管（Gitee Pages、GitHub Pages、Vercel、Netlify、对象存储静态网站等），将发布目录指向 `demo/` 即可，无需构建、环境变量或服务端。

当前线上地址（GitHub Pages）：https://1ouxilisi.github.io/ev-car-rag-bot-demo/

## 分流口径（与后端 `deploy/rag_qa.py` 对齐）

1. **实体白名单**：提到白名单品牌下未收录型号 → `unknown_model` 拦截；
2. **意图关键词**：理财、创作、法律文书、编程、天气等 → `intent_block` 拦截；
3. **词覆盖检索**：问题词与预置问答对/关键词/参考资料的覆盖度低于阈值 0.30 → `low_sim` 兜底；
4. **命中**：返回归档评测中的预置答案与参考片段。

## 多轮记忆与工具轨迹（前端预置演示）

- **会话记忆**：前端内存记录最近成功作答轮次（`记忆 N 轮`标签）；当前问题未带型号时沿用上一轮车型做检索增强；`清空对话`重置本地状态。仅成功轮次计入，拦截/兜底轮次不污染上下文，与后端口径一致。
- **工具轨迹**：部分预置问答携带 `tools` 字段（`estimate_charge_time` / `lookup_vehicle_spec`），页面渲染工具名、参数与结果摘要，对应后端 `deploy/tools.py` 的 Function Call 骨架。
- 以上均为浏览器内预置展示；模型是否发起 tool_call、多轮指代消解效果需在线兼容端点复跑验证，本地不产出在线结论。

## 数据维护

- 新增演示问答：在 `qa_data.js` 的 `qa` 数组追加 `question / answer / keywords / refs`，并同步后端知识库与评测集。
- 复核阈值与分流：`python demo/_calibrate.py`，输出 43 条评测集的逐条判定与阈值扫描（前端预置答案覆盖领域内精选 22 条，其余长尾由兜底回复处理）。

## 边界说明

- 本页面是**前端演示原型**：答案取自 `eval/eval_result.json` 归档结果，不调用在线大模型；浏览器内的检索为词覆盖轻量匹配，不等同后端的神经向量检索；工具轨迹与会话记忆为前端预置，不等同在线模型的真实工具调用与多轮推理。
- 完整 LoRA 微调 → 合并导出 → vLLM 部署 → 神经向量 RAG 链路见仓库 `deploy/`、`train/` 与 `docs/eval_report.md`。
- 所有车型与参数均为虚构演示语料，不对应任何真实品牌。
